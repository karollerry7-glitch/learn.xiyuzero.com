# 微信小程序备案指南（个人主体）

> 目的：获得小程序备案号。**2023-09 之后注册的小程序，未完成备案不能提交审核上架**，这是上线的硬性前提。
> 全程线上办理，免费，个人主体即可，预计 20 分钟填完 + 1~20 个工作日审核。

## 一、入口

1. 浏览器打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)，用**小程序管理员微信**扫码登录
2. 选择小程序「西语Zero」（AppID `wxccbb540a3394ce9d`）
3. 进入 **设置 → 基本设置 → 小程序备案**（或首页横幅「去备案」）

## 二、需要准备的材料

| 材料 | 说明 |
|---|---|
| 本人身份证 | 正反面彩色照片/扫描件，清晰无遮挡，在有效期内 |
| 手机号 + 邮箱 | 接收核验信息（主体负责人 = 小程序负责人可同一人） |
| 通信地址 | 实际居住地址，精确到门牌号 |
| 人脸核验 | 白色/浅色背景，不戴帽子口罩（现场用手机完成） |

## 三、填写流程

1. **主体信息**：主办单位地区 → 个人 → 上传身份证 → 自动填充 → 核对 → 验证
2. **小程序信息**：
   - 名称：西语Zero（与后台一致）
   - 服务内容标识：选择「教育 → 在线教育/学习类工具」（按页面实际可选项勾选，不涉及前置审批则选「以上都不涉及」）
   - 备注（20-200 字）参考：`西班牙语词汇学习工具，提供分等级词库浏览、五维学习流程（发音、含义、语法、词块、例句）、复习练习与个人学习进度记录`
3. **负责人信息**：姓名、身份证号、手机、应急手机、邮箱 → 上传身份证正反面 → 人脸核验
4. 提交

## 四、审核时间线

| 阶段 | 时长 | 注意 |
|---|---|---|
| 腾讯平台初审 | 1-2 个工作日 | 被退回会短信+站内信通知，按提示修改重交 |
| **工信部短信核验** | — | **12381 发出的短信，24 小时内必须点链接完成**，错过会被退回 |
| 省管局终审 | 各省 1-20 个工作日 | 多数省份 3-7 天 |

## 五、常见坑

- **短信核验超时**是最常见退回原因，提交后保持手机畅通
- 一个主体已有网站 ICP 备案 ≠ 小程序自动备案，两套流程互不覆盖
- 备案期间可以继续开发调试（开发者工具不受影响），只是不能提审上架
- 备案下来后，后台「基本设置」里会显示备案号

## 六、备案之后（真机可用的两条路）

1. **微信云托管**（推荐，见 `docs/云托管部署指南.md`）：小程序 `callContainer` 直连后端，**不需要域名备案**，备案号下来即可真机联调
2. **域名备案**（可选，长期）：`learn.xiyuzero.com` 走腾讯云网站备案，后端迁境内，Web 端也受益——周期另计 15-20 个工作日
