# 微信云托管部署指南（免域名备案的真机方案）

> 原理：小程序通过 `wx.cloud.callContainer` 直连云托管里的容器后端，
> **不走 HTTPS 域名，因此不受「合法域名必须备案」限制**。
> 我们的 API 是标准 Next.js Request/Response，容器内外行为一致；数据仍在 Vercel Blob，不需要迁移。

## 已经准备好的（代码层面 ✅）

- `Dockerfile`：Next.js standalone 多阶段构建，监听 `$PORT`（云托管默认注入 80）
- `next.config.ts`：`DOCKER_BUILD=1` 时输出 standalone（Vercel 构建不受影响）
- `.dockerignore`
- 小程序 `src/services/request.ts`：`TARO_APP_USE_CLOUDBASE=1` 时 `/api/*` 自动改走 `callContainer`，其余逻辑（401 重登、错误处理）完全不变

## 你需要做的（约 15 分钟，需小程序管理员账号）

### 1. 开通云托管 + 生成 CLI 密钥

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 你的小程序（AppID `wxccbb540a3394ce9d`）
2. 左侧「云托管」（或 [wx.cloud.weixin.qq.com](https://wx.cloud.weixin.qq.com)）→ 开通环境（按量计费，有小额免费额度）
3. 记下**环境 ID**（形如 `prod-xxxx`）——云托管与环境已默认打通小程序
4. 控制台 →「设置」→「全局设置」→「CLI 密钥」→ 生成密钥（管理员扫码）
   - 把密钥内容保存为 `learn.xiyuzero.com/cloudbase.key`（已 gitignore，绝不入库）
   - 平台不保存密钥，丢了只能重新生成

### 2. 一键部署（我已备好脚本）

```bash
cd learn.xiyuzero.com
bash scripts/deploy-cloudbase.sh <你的环境ID>
```

脚本自动完成：CLI 登录 → 上传代码（.dockerignore 排除密钥/node_modules）→ 云端构建 Dockerfile → 注入 4 个生产环境变量（与 Vercel Production 完全一致，token 两端通用）→ 全量发布。

> 手动等价命令（脚本内部即此）：
> ```bash
> wxcloud login --appId=wxccbb540a3394ce9d --privateKey=cloudbase.key
> wxcloud run:deploy . --envId=<环境ID> --serviceName=xiyuzero-api \
>   --containerPort=3000 --releaseType=FULL --noConfirm \
>   --envParams="AUTH_SECRET=..&BLOB_READ_WRITE_TOKEN=..&WX_APPID=..&WX_APP_SECRET=.."
> ```

### 2b.（备选）控制台上传

不开 CLI 密钥也可以：云托管控制台 →「服务与版本」→ 新建服务 `xiyuzero-api` → 上传方式选「本地代码」→ 选择 `learn.xiyuzero.com` 目录（识别 Dockerfile 云端构建）。但服务环境变量需要手动添加（值从 `.env.production.local` 复制）：

| 环境变量 | 值 |
|---|---|
| `BLOB_READ_WRITE_TOKEN` | 从 Vercel 项目设置复制（Blob 读写令牌） |
| `AUTH_SECRET` | 与 Vercel Production 一致（两端 token 通用） |
| `WX_APPID` / `WX_APP_SECRET` | 与 Vercel 一致（登录用） |

### 3. 小程序切换到云托管通道（部署完成后 1 分钟）

拿到环境 ID 后即可全自动：`wxcloud service:list --envId=<环境ID>` 查出服务默认域名，然后编辑 `xiyuzero-miniprogram/.env`：

```bash
# ⚠️ TTS 发音走 InnerAudioContext.src（downloadFile 域名校验），
#    不经过 request 层 —— 必须把 API 基址也指到云托管默认域名，
#    并把该域名加进小程序后台「downloadFile 合法域名」。
#    云托管默认域名为腾讯已备案域名，可以直接添加。
TARO_APP_API_BASE=https://<云托管服务默认域名>   # service:list 查到的 DefaultPublicDomain
TARO_APP_USE_CLOUDBASE=1                          # /api/* 数据请求走 callContainer（免域名校验）
TARO_APP_CLOUDBASE_ENV=你的环境ID
TARO_APP_CLOUDBASE_SERVICE=xiyuzero-api
```

然后重新构建并在开发者工具验证：

```bash
cd xiyuzero-miniprogram
npm run build:weapp
```

开发者工具打开后：首页能加载词库概览 = 云托管通道已生效（可以在「详情 → 本地设置」里**取消勾选**「不校验合法域名」再验证一次，模拟真机条件）。

### 4. 真机预览

工具栏「预览」→ 手机扫码。真机上走 callContainer 不需要任何域名配置，只要小程序备案已完成即可通过审核上架。

## 费用参考

- 云托管按量计费：小规模（几百 DAU 以内）通常每月几元到几十元；有免费额度
- CPU/内存弹性伸缩默认即可，无需调大

## 回退

把 `.env` 里 `TARO_APP_USE_CLOUDBASE` 删除或改为 `0`，重新 `build:weapp` 即回到 Vercel 域名通道——双向切换零成本。
