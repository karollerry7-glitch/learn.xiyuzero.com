# 微信云托管部署指南（免域名备案的真机方案）

> 原理：小程序通过 `wx.cloud.callContainer` 直连云托管里的容器后端，
> **不走 HTTPS 域名，因此不受「合法域名必须备案」限制**。
> 我们的 API 是标准 Next.js Request/Response，容器内外行为一致；数据仍在 Vercel Blob，不需要迁移。

## 已经准备好的（代码层面 ✅）

- `Dockerfile`：Next.js standalone 多阶段构建，监听 `$PORT`（云托管默认注入 80）
- `next.config.ts`：`DOCKER_BUILD=1` 时输出 standalone（Vercel 构建不受影响）
- `.dockerignore`
- 小程序 `src/services/request.ts`：`TARO_APP_USE_CLOUDBASE=1` 时 `/api/*` 自动改走 `callContainer`，其余逻辑（401 重登、错误处理）完全不变

## 你需要做的（约 15 分钟，需小程序管理员账号）

### 1. 开通云托管

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 你的小程序
2. 左侧「云托管」（或 wx.cloud.weixin.qq.com）→ 开通环境
3. 记下**环境 ID**（形如 `prod-xxxx`）——云托管与环境已默认打通小程序

### 2. 部署服务

1. 云托管控制台 →「服务与版本」→ 新建服务，名称建议 `xiyuzero-api`
2. 上传方式选「本地代码 / Git」，代码根目录选 `learn.xiyuzero.com` 仓库
   （识别 `Dockerfile` 自动构建；也可用控制台在线构建）
3. 环境变量（服务设置里配置，每个都要加）：

| 环境变量 | 值 |
|---|---|
| `BLOB_READ_WRITE_TOKEN` | 从 Vercel 项目设置复制（Blob 读写令牌） |
| `AUTH_SECRET` | 与 Vercel 环境一致的随机密钥（两端一致，token 才通用） |
| `WX_APPID` / `WX_APP_SECRET` | 与 Vercel 一致（登录用） |
| （后续接支付再加 `WXPAY_*` 系列） | 见 `docs/微信支付接入指南.md` |

4. 部署完成后，在「服务设置」里确认调用路径 `/api/*` 生效（控制台有测试功能，试 `GET /api/units?pageSize=1`）

### 3. 小程序切换到云托管通道

编辑 `xiyuzero-miniprogram/.env`：

```bash
TARO_APP_API_BASE=https://learn.xiyuzero.com   # 保留（Web/H5 兜底）
TARO_APP_USE_CLOUDBASE=1
TARO_APP_CLOUDBASE_ENV=你的环境ID
TARO_APP_CLOUDBASE_SERVICE=xiyuzero-api
```

然后重新构建并在开发者工具验证：

```bash
cd xiyuzero-miniprogram
npm run build:weapp
```

开发者工具打开后：首页能加载词库概览 = 云托管通道已生效（可以在「详情 → 本地设置」里**取消勾选**「不校验合法域名」再验证一次，模拟真机条件）。

### 4. 真机预览

工具栏「预览」→ 手机扫码。真机上走 callContainer 不需要任何域名配置，只要小程序备案已完成即可通过审核上架。

## 费用参考

- 云托管按量计费：小规模（几百 DAU 以内）通常每月几元到几十元；有免费额度
- CPU/内存弹性伸缩默认即可，无需调大

## 回退

把 `.env` 里 `TARO_APP_USE_CLOUDBASE` 删除或改为 `0`，重新 `build:weapp` 即回到 Vercel 域名通道——双向切换零成本。
