# 微信支付接入指南（代码已就绪，只差商户号）

> 支付集成代码 **已全部完成并 env-gated**：
> 未配置商户环境变量时，`/api/orders` 返回 501 `PAYMENT_NOT_AVAILABLE`，
> 小程序弹「支付功能即将上线」——即当前第一版体验，随时可平滑开启。

## 前置条件（你需要办理）

微信支付商户号需要主体资质，三选一：

| 路径 | 说明 |
|---|---|
| **已有营业执照/个体户** | 到 [pay.weixin.qq.com](https://pay.weixin.qq.com) 申请商户号，绑定小程序 AppID，通常 1-3 天下号 |
| 注册个体工商户 | 各地线上可办（成本低），拿到执照后走上一行 |
| 暂不办理 | 支付通道保持关闭，不影响其他功能 |

## 下号后要拿的四样东西

商户平台（账户中心 → API 安全）：

1. **商户号 mchid**（10 位数字）
2. **API 证书序列号**（申请 API 证书后可见，40 位十六进制）
3. **商户私钥** `apiclient_key.pem` 全文（申请证书时下载）
4. **APIv3 密钥**（自己设置的 32 位字符串）

另外在「产品中心 → AppID 账号关联」里把小程序 `wxccbb540a3394ce9d` 关联到商户号。

## 配置环境变量（Vercel + 云托管两处都要）

```
WXPAY_MCHID=你的商户号
WXPAY_SERIAL_NO=证书序列号
WXPAY_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\n...(apiclient_key.pem 全文，换行用 \n)\n-----END PRIVATE KEY-----
WXPAY_APIV3_KEY=32位APIv3密钥
WXPAY_APPID=wxccbb540a3394ce9d        # 缺省会回落 WX_APPID，可不设
WXPAY_NOTIFY_URL=https://learn.xiyuzero.com/api/pay/notify   # 缺省即此值
```

配置完成后**无需改任何代码**：下单 → `wx.requestPayment` → 回调验签 → 自动开通/续期会员，全链路即刻生效。

## 已实现的安全措施（代码层面）

- **金额只信服务端**：`priceOfCycle` 统一定价（月 ¥19.9 / 年 ¥128），客户端不传价格
- **回调验签**：平台证书验签（证书缓存 12h 自动轮换，serial 未知自动刷新）
- **AES-256-GCM 解密**回调报文（APIv3 密钥）
- **金额对账**：实收 ≠ 订单定价 → 订单关闭不开通（防篡改）
- **幂等结算**：重复回调 / 主动查单都走 `settleOrder`，不会重复加时长
- **续期叠加**：从 `max(现在, 现有到期时间)` 起算，续费不损失剩余时长
- **回调丢失兜底**：小程序支付后轮询 `/api/orders/{id}`，服务端会向微信主动查单补结算
- **订单归属**：查单只返回本人订单（404 不泄露存在性）；结算只信任订单内 userId
